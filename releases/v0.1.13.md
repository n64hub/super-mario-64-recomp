A fix for the sound at each screen change, and an update of the renderer and runtime every recomp of this project shares. Like v0.1.12 it contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.13-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.13-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Fixed:**

- The sound no longer breaks up for half a second after each screen change (the title, the file select, entering a level).
- A graphics device lost to a driver reset or a GPU that goes away is replaced, and the game draws on, instead of stopping.
- An interpolated frame no longer pulls a vertex towards a different one's last place, which could stretch a triangle for a frame.

The last two come with N64Recomp-browser v0.214.0's renderer and runtime.

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
