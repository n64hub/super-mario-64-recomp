Coins out at Draw Distance's range, and an update of the renderer and runtime every recomp of this project shares. Like v0.1.14 it contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.15-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.15-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Fixed:**

- With Draw Distance on High, rings, lines and arrows of coins are drawn as far away as single coins, out to 16,000 units, instead of appearing only once Mario is within 2000 units of them. They are still made only as he comes near, as in the game.
- A frame that runs late no longer shows a half-drawn picture for one frame.
- A 2D image cut at the screen's edge moves smoothly between the game's frames, without a line of what is behind it showing.
- 32 more controllers are mapped, and 17 mappings are updated, from SDL's controller database.

The second and third come with N64Recomp-browser v0.242.0's renderer and runtime.

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
