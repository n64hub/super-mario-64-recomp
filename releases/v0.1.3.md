Fixes for the falling snow, the cannon's view in widescreen, and the shared renderer and runtime. Like v0.1.2 it contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.3-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.3-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The falling snow** (Cool, Cool Mountain, Snowman's Land) no longer flickers as Mario moves with smooth motion on: each flake stood half a step off on every frame drawn between two of the game's.
- **The cannon's view in widescreen** draws its circle again, without the slanted black edge on the left.
- **Fewer drawing glitches in the shared renderer:** surfaces the game cuts out by coverage show instead of drawing black, a copy of the picture reaching past the 4:3 area in a wide window draws its visible part, and on a busy PC a frame no longer flashes with the next frame's 3D in it.
- **Linux:** a crash with Mesa's software Vulkan is fixed.
- **Stability fixes in the shared renderer and runtime.** RT64 no longer crashes when a game draws before it has set up its camera, a game that reads its code in small pieces no longer crashes, and reading past the end of a Flash save wraps around as on a console instead of crashing. None of these was seen in this game; they came from fixes for other recomps that use the same code.

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
