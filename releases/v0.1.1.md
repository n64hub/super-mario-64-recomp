Super Mario 64: Recompiled v0.1.1 for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.1-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.1-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What's new:**

- **No black bars with Aspect Ratio Expand.** The USA version keeps 8 black lines at the top and the bottom of its picture, which a television's overscan hid; they were stretched into bars across the whole window. With Expand the picture now fills the window from top to bottom, in the levels, the castle and the act select alike. Aspect Ratio Original keeps them, as the console draws it.
- **No Rumble Strength slider.** The USA release has no Rumble Pak support (rumble came with the later Japanese *Shindou* edition), so the slider did nothing and is gone.
- **Mods are documented.** The [README's Mods section](https://github.com/n64hub/super-mario-64-recomp#mods) says what the Mods tab loads: RT64 texture packs (`.rtz`) made for this ROM and code mods (`.nrm`) built for this recomp. Packs for the PC ports (sm64ex, Render96) and GLideN64/Rice texture packs don't load.

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
