An icon of its own. Like v0.1.3 it contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.4-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.4-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **An icon of its own:** the game has its own icon, a golden star over green hills, drawn for the project (nothing in it comes from the game). It shows on the program in Explorer and the taskbar, on the game's window (on Linux too, where the window had no icon before) and beside the game in the launcher's menu. Before it was a text tile with the game's initials.

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
