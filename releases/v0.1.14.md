A fix for the title's Mario head and its sparkles at a display rate above the game's, and an update of the renderer and runtime every recomp of this project shares. Like v0.1.13 it contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.14-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.14-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Fixed:**

- The title's Mario head no longer turns sideways and winks for a frame as it grows in, and the star cursor's sparkles no longer flash up where the game drew none, in the frames drawn between the game's own (Framerate Display).
- Video memory the game draws into at a new place and then leaves is freed, so it no longer grows the longer you play.
- A 2D image the game moves while it animates moves smoothly between the game's frames, rather than a step at a time.

The last two come with N64Recomp-browser v0.232.0's renderer and runtime.

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
