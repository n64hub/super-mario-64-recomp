Super Mario 64: Recompiled v0.1.2 for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (*Super Mario 64 (U)*, a big-endian `.z64`, SHA-1 `9bef1128717f958171a4afac3ed78ee2bb4e86ce`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SuperMario64Recompiled-v0.1.2-windows-x64.zip` and run `SuperMario64Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SuperMario64Recompiled-v0.1.2-linux-x64.tar.gz` and run `SuperMario64Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What's new:**

- **Rumble.** A gamepad now rumbles as a Rumble Pak does in the Japanese *Shindou* edition, the later release that added it (the USA release has none): a ground pound, a long or triple jump's landing, a hit, a star, a coin worth more than one, the cannon, a pipe, Bowser's throw, nearly drowning, the menus' choices and the rest, about 130 places, each with Shindou's own timing and strength. It is Shindou's own rumble code, run beside the USA game's. The **Rumble Strength** slider on the General tab is back and sets how strong it is (25% by default); 0 turns it off, as the USA release plays.

The [README](https://github.com/n64hub/super-mario-64-recomp#readme) has every setting and how to build it yourself.
